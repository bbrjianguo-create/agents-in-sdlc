通过真实场景、完整的应用程序和共享的待办事项列表，探索贯穿整个软件开发生命周期的 GitHub Copilot。将以迭代方式规划变更、创建代码、测试行为、审查拉取请求，并借助智能体管理工作。

## 场景

假设你是 Tailspin Toys 的新开发人员。这是一家虚构的公司，为开发者主题的桌游提供众筹服务。团队的待办事项已经作为 GitHub issue 创建好，可以直接领取。其中既有筛选和分页等功能工作，也有可访问性和编码标准等质量改进。

## 选择工作环境

GitHub Copilot 可在各种工作环境中使用。请选择符合自己构建方式的环境。每个工作坊都有各自的设置步骤，并使用同一个 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。体验计划模式和 Autopilot 模式、说明、技能、自定义智能体、Playwright MCP、Agent Merge 以及实用的斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行智能体会话、切换会话模式、在画布上协作，并管理 GitHub issue 和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub issue 分配给异步智能体，引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。

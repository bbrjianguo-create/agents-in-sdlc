Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software con escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar pull requests y gestionar el trabajo con agentes.

## Escenario

Eres un nuevo desarrollador de Tailspin Toys, una empresa ficticia que ofrece crowdfunding para juegos de mesa con temática de desarrollo. El backlog de tu equipo ya está registrado como incidencias de GitHub, listo para que lo abordes. Incluye trabajo de funcionalidades, como el filtrado y la paginación, junto con mejoras de calidad, como la accesibilidad y los estándares de código.

## Elige tu entorno

GitHub Copilot te acompaña allí donde trabajes. Elige el entorno que mejor encaje con tu forma de desarrollar. Cada taller empieza con su propia configuración y usa el mismo escenario de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes en tu terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y comandos de barra prácticos.

### [GitHub Copilot app][app]

Ejecuta sesiones de agente en paralelo, cambia de modo de sesión, colabora en lienzos y gestiona incidencias y pull requests de GitHub en la aplicación de escritorio.

### [Agente en la nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa los pull requests que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
